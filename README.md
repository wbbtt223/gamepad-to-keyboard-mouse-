# 🎮 Gamepad Mapper · 手柄当键盘鼠标

**把手柄变成一套完整的无线键盘 + 鼠标。**

手柄往电脑上一插，人往沙发上一躺 —— 刷视频、翻网页、打字、语音输入、调音量，全靠手柄搞定，不用再够键盘。

纯 Python 写的小工具：用 `pygame` 轮询手柄，用 Windows `SendInput` 模拟键鼠，自带一个**浏览器控制台**（`http://127.0.0.1:8765`），所有映射、灵敏度、连发频率都能边用边改、改完立刻生效，不用重启。

> English summary: Turn any gamepad into a full wireless keyboard + mouse on Windows. Pure Python (pygame + ctypes/SendInput), with a built-in browser console for live remapping.

## 📦 环境要求

- **Windows**（输入注入走 `SendInput`，其它平台不可用）
- **Python 3.9+**
- 一个能连上电脑的手柄
- 依赖只有一个：`pygame`

## 🚀 快速开始

### 方式一：双击 `run.bat`（推荐）

脚本会自动建独立虚拟环境 `.venv`、装好 pygame、然后启动，全程不用你操心。第一次运行会多花十几秒装依赖，之后就秒开。

### 方式二：手动

```bash
pip install -r requirements.txt
python gamepad_mapper.py
```

命令行参数：

```bash
python gamepad_mapper.py            # 打开浏览器控制台（推荐）
python gamepad_mapper.py --nogui    # 无界面，直接按 config.json 跑
python gamepad_mapper.py --list     # 列出手柄
python gamepad_mapper.py --check    # 环境自检（Python / pygame / SendInput / 手柄）
```

启动后浏览器会自动打开 `http://127.0.0.1:8765` —— 那就是控制台。重复启动会提示「已在运行」，不会开两个抢输入。

## 🖥 浏览器控制台

打开 `http://127.0.0.1:8765`，你能看到 / 能做：

- **实时状态**：每个按键、两根摇杆的原始坐标、累计点击 / 按键 / 滚动计数
- **映射表**：每一行 = 一个手柄键，选动作（鼠标左键 / 键盘按键 / 组合键 / 语音输入 / 滚轮 / 开关映射…）、触发方式（单击 / 按住 / 连发）、频率
- **摇杆当鼠标**：左摇杆和右摇杆**各自**的灵敏度、死区、反转 Y，互不影响
- **滚轮**：满推速度、死区、加速曲线、平滑度
- **语音输入**：触发用哪个组合键（默认 `Win+H`）
- **保存配置 / 恢复默认 / 退出程序**

改任何一格都会立刻写进 `config.json` 并实时生效，不用重启。

## ⚙️ 配置说明（`config.json`）

程序启动时读 `config.json`，日志里改了什么就存什么。关键字段：

```jsonc
{
  "rapid_hz": 20.0,              // 全局默认连发频率（次/秒）
  "rapid_delay": 0.4,            // 连发「启动延迟」（秒）：按下后等这么久才开始连发
  "double_click_gap": 0.04,      // 双击间隔（秒）
  "hotkey": { "enabled": true, "key": "f12", "ctrl": true },
  "voice_hotkey": "win+h",       // 语音输入组合键

  "mouse": {
    "stick": "left",             // 左摇杆是否当鼠标：left / right / both / none
    "sensitivity": 1400.0,       // 【左摇杆】灵敏度
    "deadzone": 0.18,            // 【左摇杆】死区
    "exponent": 1.6,             // 【左摇杆】加速曲线
    "invert_y": false,           // 【左摇杆】反转 Y

    "right_stick_scroll": false, // 右摇杆当滚轮？默认关（滚轮交给十字键上下）
    "right": {
      "mouse": true,             // 【右摇杆】也当鼠标
      "sensitivity": 500.0,      // 【右摇杆】灵敏度 —— 和左摇杆完全独立
      "deadzone": 0.18,
      "exponent": 1.8,
      "invert_y": false
    },

    "scroll": { "axis": 3, "speed": 6.0, "deadzone": 0.22 }   // 右摇杆滚轮参数
  },

  "buttons": {
    "0":  { "action": "mouse_left",  "mode": "hold",  "hz": 20, "key": "" },
    "101":{ "action": "key",         "mode": "tap",   "hz": 1.2,"key": "right" }
  }
}
```

**关于左右摇杆灵敏度**：左摇杆读 `mouse.sensitivity`，右摇杆读 `mouse.right.sensitivity`，两套参数各存各的，改一个绝不影响另一个。默认左 1400 / 右 500，右摇杆约为左摇杆的 1/3，适合瞄准和点小按钮。

**关于 `mode`**：

- `tap` —— 按一下发一次（十字键快进就是它；注意：按住了也不会有任何持续动作）
- `hold` —— 按下保持、松开释放（A 键就是它：快点=单击，长按=按住不放）
- `rapid` —— 按下先发一次，**超过 `rapid_delay` 后**再按 `hz` 频率连续触发（连点、连发）

**关于 `rapid_delay`（连发启动延迟）**：`rapid` 模式如果没有这个延迟，按下就立刻开始连发，
一次「点一下」（几十毫秒）也会补发 2~3 次 —— 真实踩过的坑：`Y = 退格` 只想删一个字母却删了 3 个。
现在按下后先等 `rapid_delay`（默认 **0.4 秒**）：

| 操作 | 行为 |
|---|---|
| 点一下（快于 0.4s 松手） | 只触发 **1 次** |
| 按住超过 0.4s | 先触发 1 次，然后按 `hz` 连续触发，松手即停 |

面板「连点 / 连发」里可以直接拖 **长按启动延迟** 滑块（0~1000 ms）；填 **0** = 按下立刻开始连发（旧行为）。
嫌长按起动慢就往小调，嫌「点一下却触发好几次」就往大调。

> 为什么键盘「长按」要用 `rapid` 而不是 `hold`：`SendInput` 注入的按键**不会触发 Windows 键盘自动重复**
> （自动重复是物理键盘驱动层的特性），所以按住 `hold` 的键盘键只会输出 1 个字符，必须由本程序按频率补发。

## ❓ 常见问题

**按手柄没反应？**
1. 先看数据线 / 蓝牙连上没有（控制台顶部会显示手柄名和按钮数）；
2. 确认映射是开着的 —— 按 Back 键或 `Ctrl+F12` 切一下，控制台顶部的状态灯会变。

**手柄待机 / 电脑睡眠唤醒后没反应，重启程序也没用？**
这叫「**假连接**」：设备节点在 Windows 里还挂着，但已经收不到任何输入了。
这时 SDL 打开的是一个**失效句柄**，而它的 `get_button()` 照样正常返回（全是 `False`），
所以程序一直以为「已连接」，永远不会去重连 —— 重启程序也只是把同一个坏句柄重新打开一遍。

本程序现在会自动识别这种情况（用 **XInput 交叉验证**：XInput 走的是 XUSB 驱动，和 SDL 的
HIDAPI 是两条独立路径），发现后自动重连；面板上会显示「假连接」告警和已自愈次数。三级处理：

| 情况 | 处理 | 什么时候用 |
|---|---|---|
| 一般掉线 | 每 2 秒自动重扫 | 不用管 |
| 长时间空闲 | 每 6 秒心跳重枚举一次（换掉"睡死但 SDL 不自知"的句柄） | 不用管 |
| 判定为假连接 | 先重扫，再**重建整个 pygame**；连续 6 次失败后退避，面板提示 | 不用管 |
| 还不行 | 面板点 **「重连手柄」** 手动触发一次重建 | 想立刻恢复 |
| 都不行 | 面板点 **「重置手柄驱动…」**（弹 UAC），让 Windows 重启设备节点 = 拔插一次 | 系统层卡死时 |

> 桌面上的 `重置手柄驱动.bat` 是同样的兜底手段（右键 → 以管理员身份运行），
> 用在**程序本身都启动不了**的时候。

**十字键只有第一下有效？**
老版本有过这个 bug：十字键在数据里是 **hat**，松开时那个键会直接从字典里消失，而不是变成 `False`。现在引擎会把「上一帧有、这一帧没有」的键补成 `False`，显式造出松开边沿。`_selftest.py` 里有 3 条走真实读取路径的回归测试锁着它。

**语音输入按了没动静？**
`Win+H` 要光标停在**能打字的输入框**里才会弹听写条；系统里也得先开一次语音功能。Win11 的「语音访问」要先在 设置 → 辅助功能 → 语音 里打开。

**改了面板里的某一格，别的设置被清掉了？**
已经修了。面板只发「被改动的字段」，服务端是**合并**（`cur.update(v)`）而不是整行替换。以前整行替换时，只改一下频率就会把同一行的动作/按键全抹掉。

**需要管理员权限吗？**
给普通窗口注入键鼠不需要。但如果目标程序是**以管理员身份运行**的（比如某些游戏、任务管理器），Windows 的 UIPI 会拦住注入 —— 这时把本程序也用管理员身份启动即可。
